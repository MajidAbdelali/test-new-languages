## How to Run the Web App

### Option 1 — Open directly in your browser (no installation required)

1. Clone or download this repository.
2. Open `index.html` in any web browser (double-click the file).

### Option 2 — Serve with Python (recommended for local development)

1. Make sure [Python](https://www.python.org/downloads/) is installed.
2. Open a terminal in the project directory.
3. Run the built-in HTTP server:

   ```bash
   python3 -m http.server 8080
   ```

4. Open your browser and navigate to `http://localhost:8080`.

### Option 3 — Serve with Node.js

1. Make sure [Node.js](https://nodejs.org/) is installed.
2. Install `serve` globally:
   ```bash
   npm install -g serve
   ```
3. Run from the project directory:
   ```bash
   serve .
   ```
4. Open your browser and navigate to the URL shown in the terminal (usually `http://localhost:3000`).
